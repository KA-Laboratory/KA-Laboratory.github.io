バスナビ運営室
Googleデータの取り扱い

更新日：2026年9月8日

バスナビ運営室は、横浜市営バスナビの運営者が自分のPC上で使用する管理ツールです。一般のアプリ利用者のGmailへの接続は提供しません。

取得するデータと利用目的

運営者が明示的に接続したGoogleアカウントのメールID、件名、送信者、日時、要約を取得し、問い合わせ・ストア通知・収益関連連絡の整理、重複防止、対応記録に使用します。Google Playのレビューおよびクラッシュ・ANRの集計情報は、アプリの品質確認と対応管理に使用します。メール本文・添付ファイルの自動取得、メール送信、レビュー返信の自動送信は行いません。

保存・削除

Googleの継続認証情報と取得したメール・レビューの記録は、運営者のWindowsアカウントに結び付けたDPAPIで暗号化し、ローカルPCへ保存します。受信一覧は新しい順に最大1,000件を保持します。運営室の各接続にある削除操作で、PC内の認証情報・取得記録・返信下書きを削除できます。Googleアカウントの接続管理からアクセス許可を取り消すこともできます。

共有・AI利用

取得データを販売したり、広告配信に利用したりしません。このGoogle連携はメールやレビューを外部AIへ自動送信せず、汎用AIモデルの学習にも使用しません。運営者自身による問い合わせ対応と品質管理のために取り扱います。

本ツールによるGoogle APIから取得した情報の利用と他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。
